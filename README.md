# 🏋️ FitLog

FitLog is a modern and responsive workout management web application that helps users explore exercises, view detailed workout information, build a daily workout plan, save favorite workouts, and track completed exercises.

The application provides an organized and interactive way to discover workouts and manage a personalized fitness routine.

## 🚀 Technologies Used

* **Next.js** — Application framework and routing
* **React** — Building interactive and reusable UI components
* **JavaScript** — Application logic and functionality
* **Tailwind CSS** — Responsive and modern styling
* **REST API** — Fetching workout and exercise data
* **Local Storage** — Persisting selected workout plans and saved workouts

## ✨ Key Features

### 🏋️ Workout Library

Explore a collection of workouts with useful information such as:

* Workout images
* Categories
* Equipment
* Duration
* Calories
* Ratings

### 📋 Workout Details

View detailed information about individual exercises, including:

* Exercise specifications
* Workout information
* Step-by-step instructions
* Required equipment
* Other relevant exercise details

### 📅 Today's Plan

Create and manage a personalized daily workout plan.

Users can:

* Add workouts to today's plan
* View planned exercises
* Remove exercises from the plan
* Track completed exercises

### ❤️ Saved Workouts

Save favorite workouts for later and easily access them from the **My Plan** section.

### ✅ Workout Tracking

Mark exercises as completed and manage workout progress directly from the daily plan.

### 📱 Responsive Design

The application is designed to provide a smooth experience across:

* Mobile devices
* Tablets
* Desktop screens

## 🛠️ Getting Started

Follow these steps to run FitLog on your local machine.

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

Check your installed versions:

```bash
node -v
npm -v
git --version
```

---

## 💻 Installation & Local Setup

### 1. Clone the Repository

```bash
git clone https://github.com/liliputdev/B14-A6-Fit-Log.git
```

### 2. Navigate to the Project Directory

```bash
cd B14-A6-Fit-Log
```

The main application is located inside the `fitlog` directory.

```bash
cd fitlog
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Application

After starting the development server, open the local URL provided by Next.js, usually:

```text
http://localhost:3000
```

---

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
